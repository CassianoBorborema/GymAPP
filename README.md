# GymApp - Gestão de Treinos 🏋️‍♂️

O **GymApp** é uma plataforma focada na organização e acompanhamento de treinos para academias. O objetivo é conectar instrutores e alunos de forma eficiente, permitindo um planejamento técnico e um feedback real sobre as atividades físicas.

## 🚀 Funcionalidades Principais

O sistema foi desenhado para resolver quatro pilares essenciais:

- **👤 Gestão de Alunos**: Cadastro e controle de perfis dos alunos, incluindo dados físicos e objetivos.
- **📋 Catálogo de Exercícios**: Registro de exercícios detalhados para serem utilizados na montagem dos treinos.
- **⚡ Geração de Treinos**: Ferramenta para instrutores criarem rotinas de treinamento personalizadas para cada aluno.
- **✅ Registro de Execução**: Espaço para o aluno confirmar a realização do treino e dar feedback sobre o esforço.

- **TypeScript**
